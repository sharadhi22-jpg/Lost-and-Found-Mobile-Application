# Campus Lost and Found Mobile Application

A Kotlin-based Android application developed to help students report, track, and recover lost and found items within a college campus. The application provides a centralized platform where users can register, log in, post lost or found items, upload images, communicate through an integrated messaging system, and mark items as recovered.

## Features

* User Registration and Login
* Session Management using SharedPreferences
* Lost and Found Item Reporting
* Image Upload and Preview
* RecyclerView-based Item Listings
* Item Detail View
* In-App Messaging System
* Mark as Received Functionality
* SQLite Database Integration
* Offline Access without Internet Connectivity

## Tech Stack

* Kotlin
* Android Studio
* SQLite
* XML Layouts
* RecyclerView
* SharedPreferences

## Project Objective

The application aims to simplify the process of recovering lost belongings within educational institutions by providing an organized, secure, and user-friendly mobile platform.
